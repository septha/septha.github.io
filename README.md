## 🌐 Website Navigation & Structure

The website is structured into 5 core sections:
1. **Home:** Executive summary introducing my role in bridging business needs with technology and data-driven solutions.
2. **About:** Professional background, core competencies, and career progression.
3. **Resume:** Career history, certifications (Google Data Analytics), and educational background.
4. **Portfolio:** Filterable project showcase organized into **Data & System Analysis** and **Web Development**.
5. **Contact:** Professional channels for career and consulting inquiries.
